Instrucciones (App Movil - Configuracion, Imagenes y Utilidades)

Te toca subir la configuracion inicial de la app, las imagenes de los logos y el cliente de API.
Primero, copia los archivos y carpetas que estan junto a este texto y pegalos en la carpeta de tu proyecto (reemplazando lo que te pida). Luego, abre la consola en el proyecto de la app movil y tira estos comandos:

1. git pull origin main
2. git add app.json
3. git add assets/
4. git add src/utils/
5. git commit -m "feat: configuracion app.json, logos y utilidades api"
6. git pull origin main
7. git push origin main

Acuerdate de avisar al terminar para que otro pueda subir.
